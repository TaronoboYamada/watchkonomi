Watchアプリのインストール手順(Xcodeの画面操作)

------------------------------------------------------------
準備するもの
------------------------------------------------------------
1. Mac( Appleのパソコン )にXcodeが入っていること
2. Apple ID( いつも使っているAppleのアカウント )
3. iPhoneとApple Watchがペアリング済みであること

------------------------------------------------------------
Watchアプリのインストール
------------------------------------------------------------
1. Xcodeで Watchkonomi.xcodeproj を開く
2. 左のサイドバーで「WatchApp」をクリックする
3.「Signing & Capabilities」タブを開く
4.「Team」の下拉ぎから、自分のApple IDの名前を選ぶ
   ( 名前がない場合: Xcodeのメニュー「Settings」→「Accounts」
     から自分のApple IDを追加する )
5. ウィンドウ一番上の中央の下拉ぎで「WatchApp」を選ぶ
6. その右の下拉ぎで、自分のApple Watchの名前を選ぶ
7. 一番上の「再生」ボタン( 三角形 )を押す
8. 数分待つ。インストールが完了する
9. Apple Watchのアプリ画面にアイコンが出れば成功

------------------------------------------------------------
iOSアプリ( 配信側 )のインストール
------------------------------------------------------------
1. ウィンドウ一番上の下拉ぎで「Watchkonomi iOS」を選ぶ
2. その右の下拉ぎで、自分のiPhoneの名前を選ぶ
3.「再生」ボタンを押す
4. 数分待つ。iPhoneにアプリがインストールされる

------------------------------------------------------------
確認方法
------------------------------------------------------------
1. iPhoneで konomitv を開く
2. iPhoneで Watchkonomi アプリを開く
3.「配信を開始」をタップする( 初回は許可を求められる )
4. すぐに konomitv へ画面を切り替える
5. Apple Watchのアプリを開くと、数秒で映像と音声が再生される
