push( GitHubへアップロード )の実行手順

------------------------------------------------------------
やること
------------------------------------------------------------
1. プロジェクトフォルダ(C:\Users\owner\opencode\watchkonomi)
   で開いたターミナル( この画面 )に、
   下の1行をそのまま貼り付けてEnterを押す

   git push -u origin main

------------------------------------------------------------
実行した時に出ること
------------------------------------------------------------
1. しばらく画面が止まる( 数秒 )
2. GitHubのログイン画面のポップアップ( ブラウザ )が出る
3. その画面で、自分のGitHubアカウント
   ( TaronoboYamada )でログインする
4. ログインが終わると、ターミナルに
   「Enumerating objects」などの文字が出る
5. 最後に「branch main set up to track remote branch」
   と出て、コマンドプロンプトに戻る
   これが出れば成功です

------------------------------------------------------------
成功の確認
------------------------------------------------------------
1. ブラウザで https://github.com/TaronoboYamada/watchkonomi
   を開く
2. ファイルの一覧が出ている
3. 上部の「Actions」タブを開く
4. ビルドが始まっている( 黄色い円マーク )
5. 数分後に緑のチェックに変われば成功
6. 緑になったら、そのビルド結果の画面を開く
7. 一番下の「ipas」というアーティファクトを
   ダウンロードする
8. 中身のIPAを2つ、デスクトップ等に置く
   ( 続きは INSTALL-NOMAC.txt の手順3以降 )

------------------------------------------------------------
エラーが出た場合
------------------------------------------------------------
- 「permission denied」や「403」が出た場合:
  ログインで選んだアカウントが
  TaronoboYamada になっていない可能性があります
  ポップアップのアカウントを確認して再実行する
- 「source path does not exist」が出た場合:
  ターミナルがプロジェクトフォルダ以外で開かれています
  フォルダを指定して開き直す
- 他のがわからないエラー:
  そのままこのチャットに貼り付けて送る
