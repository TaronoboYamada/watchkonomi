# Mac を借りて Apple Watch 実機にインストールする手順

借りる時間の目安: **2〜3時間**(Xcode 未インストールの Mac だと +1〜2時間)
借りる前に確認することは、このファイルの最後「事前チェック」を見てください。

------------------------------------------------------------
全体の流れ
------------------------------------------------------------
1. Xcode をインストール(未インストールなら。8〜12GB のダウンロード)
2. Homebrew と XcodeGen をインストール
3. このプロジェクトをダウンロード(git clone)
4. Xcode プロジェクトを生成して開く
5. Xcode に Apple ID(無料)を登録
6. iPhone を Mac に接続し、Watch を Xcode から見えるようにする
7. Watch 側で「デベロッパモード」を有効化
8. Xcode で実行(Cmd+R)→ Watch にインストールされる
9. Watch 上で開発者を信頼

------------------------------------------------------------
1. Xcode のインストール
------------------------------------------------------------
1. App Store を開く
2. 「Xcode」で検索してインストール(8〜12GB、回線によって 30分〜2時間)
3. インストール後、一度起動して利用規約に同意し、追加コンポーネントの
   インストールを許可する
- すでに Xcode が入っている Mac ならこの手順は不要(バージョン 16 以上
  が理想。Xcode → About Xcode で確認)

------------------------------------------------------------
2. Homebrew と XcodeGen
------------------------------------------------------------
1. 「ターミナル」を開く(アプリケーション → ユーティリティ → ターミナル)
2. Homebrew 未インストールなら、以下をコピーして実行:
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   (画面の指示に従う。Mac のログインパスワードを聞かれる)
3. XcodeGen をインストール:
   brew install xcodegen

------------------------------------------------------------
3. プロジェクトのダウンロード
------------------------------------------------------------
ターミナルで:
   cd ~/Desktop
   git clone https://github.com/TaronoboYamada/watchkonomi.git
   cd watchkonomi/v2

(git がないと言われたら、macOS は「コマンドライン・デベロッパツール」の
 インストールを促すダイアログを出すので「インストール」を選ぶ)

------------------------------------------------------------
4. Xcode プロジェクトの生成とオープン
------------------------------------------------------------
ターミナルで:
   xcodegen generate
   open Watchkonomi.xcodeproj

Xcode が開く。

------------------------------------------------------------
5. Xcode に Apple ID を登録
------------------------------------------------------------
1. Xcode メニュー → Settings(または環境設定)→ Accounts
2. 左下の「+」→ Apple ID でサインイン
   (普段 iPhone で使っている Apple ID で OK、無料のままで良い)

------------------------------------------------------------
6. iPhone を接続し Watch を見えるようにする
------------------------------------------------------------
1. iPhone を USB ケーブルで Mac に接続
2. iPhone で「このコンピュータを信頼しますか」→ 信頼
3. Watch は iPhone とペアリング済みのまま、**同じ Wi-Fi に接続**しておく
   (Bluetooth も ON)
4. Xcode メニュー → Window → Devices and Simulators
5. 左リストに iPhone が出る。その下に「 paired Apple Watch」として
   Watch 名が表示されれば OK
6. Watch の行に⚠や「Prepare for development」等が出たら、その指示に
   従って準備を完了させる(数分、Watch は充電器に載せておく)

------------------------------------------------------------
7. Watch 側でデベロッパモードを有効化
------------------------------------------------------------
1. Apple Watch で: 設定 → プライバシーとセキュリティ → デベロッパモード
2. スイッチを ON → 再起動を求められたら再起動
※ 項目が表示されない場合は、先に手順 8 を一度試すと項目が出ることがある

------------------------------------------------------------
8. Watch にインストール(実行)
------------------------------------------------------------
1. Xcode の左上のスキーム選択(再生ボタンの横)で「Watchkonomi」を選ぶ
2. その右のデバイス選択で、**自分の Apple Watch の実機名**を選ぶ
   (iPhone 実機や Simulator ではなく Watch の名前)
3. ターゲットごとの署名設定:
   - プロジェクト設定で「Watchkonomi」ターゲット → Signing & Capabilities
     → Team: 自分の Personal Team を選択
   - 必要なら「WatchkonomiCompanion」ターゲットも同様に Team を選択
   - 「Signing Certificate: Apple Development」でエラーが出たら
     「Automatically manage signing」にチェック
4. 再生ボタン(Cmd+R)を押す
5. 初回は Watch での準備(数分)→ 自動でアプリが起動する

------------------------------------------------------------
9. Watch 上で開発者を信頼
------------------------------------------------------------
初回起動で「信頼されていないデベロッパ」的な表示が出たら:
1. Watch で: 設定 → 一般 → VPNとデバイス管理
2. 自分の Apple ID をタップ → 信頼

これで Apple Watch のホーム画面に Watchkonomi が出ます。

------------------------------------------------------------
動作確認
------------------------------------------------------------
1. Watch を KonomiTV サーバーに届く Wi-Fi(Tailscale 含む)に接続
2. Watchkonomi を開く → チャンネル一覧 → チャンネルタップ → 再生
   (再生開始まで 10〜20 秒かかるのは正常)

------------------------------------------------------------
注意点
------------------------------------------------------------
- 無料 Apple ID の署名は **7日間**で期限切れ。7日ごとに再度
  Cmd+R が必要(借り直し)。常用するなら有料開発者登録(年 ¥12,980)推奨
- 有料登録すればこの手順は同じで、期限が 1 年になり、TestFlight 配信
  (Windows だけで完結)も使えるようになる

------------------------------------------------------------
事前チェック(借りる前に)
------------------------------------------------------------
- [ ] Mac は macOS 14 以上(できれば 15 以上)
- [ ] できれば **Xcode 済み**の Mac(App Store で「入手済み」表示になれば速い)
- [ ] 自分の Apple ID とパスワードを覚えている
- [ ] iPhone の USB ケーブル(Lightning または USB-C、データ対応品)
- [ ] iPhone と Watch のペアリングが済んでいる
- [ ] 家の Wi-Fi に Mac・iPhone・Watch を繋げられる
- [ ] Watch を充電できる環境(インストール中は充電器推奨)
- [ ] ディスク空き容量 20GB 以上(Xcode 用)
