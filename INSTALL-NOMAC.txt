Mac PC を使わないでインストールする方法

------------------------------------------------------------
全体の流れ
------------------------------------------------------------
1. このプロジェクトを GitHub にアップロードする
2. GitHub が自動でビルドし、インストールファイル(IPA)を作る
3. GitHub のページから IPA を2つダウンロードする
4. Windows に AltStore というソフトを入れる
5. iPhone を USB で PC に接続し、AltStore で IPA をインストールする
6. Apple Watch は自動でアプリが反映される

------------------------------------------------------------
手順1: GitHub にアップロード
------------------------------------------------------------
1. github.com でプロジェクトのリポジトリを作る
2. この PC で git コマンドを使って push する
   ( push のやり方がわからなければ聞いてください )
3. push すると GitHub Actions が自動でビルドが始まる
4. リポジトリの「Actions」タブで、ビルドが緑の成功になるのを待つ
   ( 数分かかります )

------------------------------------------------------------
手順2: IPA をダウンロード
------------------------------------------------------------
1. GitHub Actions の成功したビルドの結果を開く
2. 一番下の「ipas」という名前のアーティファクトをダウンロードする
3. 中身は2つのファイルです
   - Watchkonomi-ios.ipa ( iPhone 側アプリ )
   - WatchApp-watch.ipa ( Apple Watch 側アプリ )
4. この2つを PC のわかりやすい場所( デスクトップ等 )に置く

------------------------------------------------------------
手順3: AltStore を入れる
------------------------------------------------------------
1. 公式サイト altstore.io から AltStore の Windows 版を
   ダウンロードしてインストールする
2. AltStore を開き、自分の Apple ID でサインインする
   ( いつも使っている Apple のアカウント )

------------------------------------------------------------
手順4: iPhone にインストール
------------------------------------------------------------
1. iPhone を USB ケーブルで PC に接続する
2. iPhone が「このコンピュータを信頼しますか」と
   聞いたら「信頼する」をタップする
3. AltStore で「My Apps」画面を開く
4. 右上の「+」ボタン( Install )を押す
5. 先ほどダウンロードした IPA を選ぶ
   - 最初は WatchApp-watch.ipa を選ぶ
   - 完了後にもう一度「+」で Watchkonomi-ios.ipa を選ぶ
6. 数分待つと iPhone にアプリがインストールされる

------------------------------------------------------------
手順5: 確認
------------------------------------------------------------
1. Apple Watch のアプリ画面に WatchApp のアイコンが出ている
2. iPhone で konomitv を開く
3. iPhone で Watchkonomi アプリを開く
4.「配信を開始」をタップする( 初回は許可を求められる )
5. すぐに konomitv へ画面を切り替える
6. Apple Watch のアプリを開くと、数秒で映像と音声が再生される

------------------------------------------------------------
注意点
------------------------------------------------------------
- 無料の Apple ID では、アプリの有効期限が7日間です
  AltStore が自動で更新してくれます
  ( PC を AltStore 開いたまま Wi-Fi に繋ぐと更新されます )
- 有料の Apple Developer( 年9800円 )に加入すると
  1年間ずっと使えるようになります
- ビルドが失敗した場合は、このチャットに教えてください
