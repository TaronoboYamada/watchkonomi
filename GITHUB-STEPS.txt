GitHubにリポジトリを作る手順( ブラウザ操作 )

------------------------------------------------------------
手順
------------------------------------------------------------
1. ブラウザで github.com を開く
2. 右上の「Sign in」で、自分のGitHubアカウントでログインする
   ( アカウントがない場合は、同じ画面から
     「Sign up」で無料作成できます )
3. 画面右上の「+」ボタンをクリックする
4. 一覧から「New repository」を選ぶ
5. 「Repository name」の欄に
   watchkonomi
   と入力する
6. その下のチェック項目( README, .gitignore 等 )は
   何もチェックしない
7. 一番下の「Create repository」ボタンを押す
8. できたページに、リポジトリのURLが表示される
   形はこうなります
   https://github.com/あなたのユーザー名/watchkonomi

------------------------------------------------------------
次にやること
------------------------------------------------------------
1. そのURLをこのチャットに貼り付けて送る
2. 残りの作業( push )はこちらで行う
3. pushする時、PCにGitHubのログイン画面が
   ポップアップで出たら、アカウントでログインする

------------------------------------------------------------
補足
------------------------------------------------------------
- リポジトリをPrivate( 非公開 )にしてもPublic( 公開 )
  どちらでも構いません
- pushが完了すると、GitHubが自動でビルドを始めます
- ビルド成功後、リポジトリの「Actions」タブから
  IPAファイルをダウンロードできます
  ( 続きは INSTALL-NOMAC.txt の手順2以降 )
